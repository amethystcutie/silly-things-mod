# Silly Things Mod

This mod adds unique weapons and items from other games

Requires Minecraft 1.21.1, [NeoForge](https://neoforged.net/), and [Kotlin For Forge](https://modrinth.com/mod/kotlin-for-forge) 5.10.0+

## Installation instructions
- [Install NeoForge](https://neoforged.net/) for 1.21.1 if you haven't already
- Download `silly_things-1.0.0.jar` from the release assets below
- Download [Kotlin For Forge](https://modrinth.com/mod/kotlin-for-forge/version/5.12.0)
- Move both .jar files into your `mods` folder (usually under [.minecraft](https://minecraft.wiki/w/.minecraft), you might have to create it)
- Launch Minecraft with the NeoForge profile

## Current items
