# Silly Things Mod

This mod adds unique weapons and items from other games

Requires Minecraft 1.21.1, [NeoForge](https://neoforged.net/), and [Kotlin For Forge](https://modrinth.com/mod/kotlin-for-forge) 5.10.0+

Current items:
- Justitia (Lobotomy Corporation)
- Mimicry (Lobotomy Corporation)

WIP:
- Solemn Lament
